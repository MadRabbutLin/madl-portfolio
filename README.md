# 摄影 / 剪辑个人作品集

React 19 + Vite 6。无需后端。

运行：`npm install`，然后 `npm run dev`。打开终端显示的本地地址，默认 http://127.0.0.1:5173 。构建：`npm run build`；构建预览：`npm run preview`。

功能：首屏混剪展示入口、原生视频播放控件、本地混剪视频临时预览、四类个人作品筛选、作品详情、关于和联系区块。版心最大 1700px，适配手机。

修改 `src/main.jsx` 的 projects 数组替换项目，修改 sampleVideo 替换正式混剪地址。图片和视频当前均为公开演示素材；项目名称为虚构版式示例。联系入口尚未配置真实信息。视频本地选择仅在当前页面临时预览，不上传、不持久保存。演示素材需联网加载。
